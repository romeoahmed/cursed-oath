# Limitless visual reference

[limitless.png](limitless.png) is the AI-generated art direction for Blue, Red, and Purple, guided by the supplied anime triptych. It serves as an art reference and README illustration, not a game capture, canon source, or runtime texture. Keep that distinction explicit wherever it is displayed.

Keep continuous, dense spherical bodies, bright centers, and crisp small color regions. Blue has dark blue inward-flowing ribbons, Red has a compact white-hot center and short radial streaks, and Purple has attached violet flows and a rearward wake. Avoid glossy material highlights, a separate outer bubble, and loose particle-cloud bodies.

The generated character geometry and environment lighting are illustrative. Runtime effects use Minecraft's vertex-color and additive rendering paths; the reference does not require new player models or dynamic lighting.
