# 战斗与领域规格

[当前原型](#当前原型)描述代码已有行为；[后续战斗规则](#后续战斗规则)及领域章节是制作目标。数值均为游戏调校，原作证据与待核细则见[来源与核验](sources.zh-CN.md)。

## 当前原型

通过管理员练习命令开放全部原型能力；操作见 [README](../README.md#run-from-source)。生存获取、领域和后期派生尚未实现。

### 咒力与动作

咒力上限为 1,000。准备时扣启动费并预留释放费；`可用咒力 = 余额 − 预留`。释放扣除预留费用，取消解除预留但保留启动费及剩余恢复时间。准备与恢复均按服务端 tick 推进；正常 20 TPS 下 20 tick 为一秒。

准备时检查资格、动作状态、资源及地形容量，释放前复核状态与资格。受伤、死亡、普通跨维度、断线或取消会结束准备。使用物品、骑乘、鞘翅飞行和游泳时不能开始施法。已释放攻击按自身规则存续，取消不会召回；苍、赫和解绑定施术者存续，已发射的茈独立完成飞行与已提交的地形工作。

未施法、恢复结束且中性防御关闭时，每 tick 恢复 2 咒力。余额与恢复负担持久化，重登和重生不补满；离线期间恢复计时暂停。练习命令可主动重置。

| 能力     | 启动费 + 释放费 | 准备 / 释放后恢复（tick） |
| -------- | --------------- | ------------------------- |
| 苍       | 15 + 85         | 12 / 16                   |
| 赫       | 25 + 125        | 18 / 24                   |
| 解       | 10 + 40         | 6 / 10                    |
| 捌       | 10 + 65         | 5 / 12                    |
| 反转自疗 | 10 + 140        | 20 / 30                   |
| 常规茈   | 80 + 420        | 50 / 60                   |

参数定义见 `Technique`、`TechniqueTuning` 和 `Fighter`；时间均为模拟时间，低 TPS 不按墙钟补发伤害。

### 术式与地形

伤害以原版生命值为单位，经原生减伤和死亡流程处理；2 点生命值对应一颗心。术式排除自身、盟友及受 PvP 规则保护的玩家。

| 能力   | 命中与输出                                                                                                                            | 地形                                                             |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| 苍     | 核心以 0.9 格/tick 飞行，射程 18 格；接触或到达射程后停留。牵引半径 12 格，伤害核心半径 3.5 格；60 tick 寿命包含飞行，六次脉冲各 8 点 | 停留中心半径最多 6 格的球形挖掘                                  |
| 赫     | 以 1.5 格/tick 飞行，射程 24 格；接触或射程耗尽时爆发。半径 10 格，峰值 96 点，按距离和冲击时遮挡衰减，沿入射方向排斥                 | 半径最多 8 格的球形挖掘                                          |
| 解     | 以最多 6 格/tick 前进，射程 48 格；宽 10 格、厚 0.36 格，每目标一次 36 点                                                             | 沿途薄切面                                                       |
| 捌     | 四格内接触后展开网格；每目标一次 `min(160, 64 + 2 × 护甲值 + 0.5 × 最大生命值)`                                                       | 接触处跨度 14 格、深度 7 格的正交切面；网格间隙保留              |
| 常规茈 | 蓝红会合后形成紫色；以 4 格/tick 前进，射程 128 格，每目标一次 360 点 | 直径 12 格的连续球体扫掠，含球冠；飞行与挖掘独立，粉碎无掉落 |

赫峰值取苍完整六段输出的两倍；目标受伤间隔、移动、遮挡和减伤会改变实际结果。苍的牵引场随核心移动并检查当前遮挡；赫按爆发时遮挡判伤，不因随后破墙追加伤害。

茈按当前飞行段连续扫掠，穿过普通地形及保留方块，不追加视线检查；每发每目标最多一次。解在推进和等待时检查接触体积与遮挡。捌的初始接触立即判伤，网格其他目标在挖掘后复核位置和遮挡；挥空、被中性防御阻止或网格区块不可用时不产生成功表现，但已提交释放仍付费。

破坏永久保留。容器、流体、不可破坏块和权限否决受保护；解与捌保留障碍后方路径，解中心路径受阻时停止。茈与球形挖掘跳过保护块；保留方块不额外保护茈后方的目标和地形。普通破坏沿用原版掉落规则。

已发射的茈不因施术者死亡而消失，仍按原始身份检查权限；到射程、世界边界、当前路径未加载处或实体模拟边界结束，已提交的地形继续处理。地形容量、时间预算及提交细节见[技术架构](architecture.zh-CN.md#命中与地形)。

### 中性防御与恢复

中性防御开启后每 tick 消耗 2 咒力，不足即关闭。当前拦截玩家/生物近战、箭和三叉戟伤害，并偏转近处来袭投射物；本 Mod 的术式另检查该防御。环境与未知伤害源不自动免疫。渐近减速、六眼筛选及专属突破规则尚未实现。

反转自疗通过原生治疗入口恢复 6 点生命值，满血时拒绝准备。目前自疗、赫和茈共用 `reversal` 资格；对外治疗、正能量攻击和熔断修复尚未实现。

### 近战与黑闪

G 消耗 5 咒力，预备一次近战，持续 60 tick。重复准备不续期或重复扣费；一次主攻击或挥空消费预备，开始术式准备、取消及过期也会清除。预备与释放术式后的恢复可并存。

原生攻击蓄力大于 90% 且目标可受影响时，预备攻击有 20% 黑闪机会。扫击不独立抽取，无下限阻止接触时不产生黑闪。以原生减伤前伤害 D 计算：普通强化为 `D × 1.15`；黑闪在 D > 0 时为 `max(2, D)^2.5`，否则为 0。最低基数是空手适配，伤害只提交一次，表现仅在实际扣除生命或吸收值后确认。

2.5 次方的出处见[威力基准](sources.zh-CN.md#黑闪的威力基准)。概率、三秒预备和最低基数是游戏规则；专注、觉醒及术式恢复尚未实现。预备按服务端收到请求的时序生效，迟到输入不追认已经结算的攻击。

## 后续战斗规则

以下是完整体系的工作规格，需逐项实现和验收。

- 身体、天赋、生得术式和习得技术分别授权；自疗、对外输出正能量、术式反转与熔断修复拆分资格。
- 每动作、命中批次和领域有独立 ID；重复请求不得重复扣费、抽取、命中或掉落。效果保留来源，结束时只清理该来源。
- 输入最多缓冲一个动作；手部、媒介和移动状态采用明确兼容表。原版移动与近战保留其服务端入口，动画不推动玩家或延迟伤害。
- 高速/转向攻击采用有界扫掠与相对运动。多段攻击定义命中间隔和累计上限；普通硬直连续衰减，撞墙附加结算每段最多一次。
- 黑闪可带来路线限定的专注或突破，训练演示不发成长奖励。恢复收益逐项定义，避免随机次数成为主线门槛。

### 两套术式的扩展

| 能力           | 制作目标与边界                                                          |
| -------------- | ----------------------------------------------------------------------- |
| 中性防御       | 可见接近/停滞、资格与精度；按伤害来源和突破路径处理，不使用通用无敌开关 |
| 苍 / 赫        | 有限的操控与空间组合；牵引和排斥保留原版碰撞，瞬移另行验证条件          |
| 常规茈及变体   | 强化咏唱、远程组合与范围茈独立建模，分别定义代价、误伤与自身影响        |
| 无量空处       | 信息过载的专属控制、对象规则与接触豁免；不用普通缓慢效果代替            |
| 解 / 捌        | 区分远距、接触与地面派生；自适应输出仍受术者能力和目标防御约束          |
| 伏魔御厨子     | 原世界中的开放领域，实体必中与方块破坏分别结算，可离开实际范围          |
| 灶（暂定译名） | 领域内外变体分开，斩击前置、束缚及对象限制待正文核验                    |
| 扩张对象的斩击 | 独立变体与阶段资格；首次使用和束缚后的发动条件分开，长期代价持久化      |

完整角色演示、成长玩家与其他使用者采用各自资格。简易领域、展延、领域必中和特殊斩击在对应规则层处理，不能仅靠提高伤害表达突破。茈、最大输出与特殊斩击不归入极之番。

## 领域、反领域与空间

### 成立与对抗

领域经历准备、形成、活跃和崩解；相持是领域间关系，熔断属于术者。每个领域声明结构、范围、目标、完成程度与结束条件。

同一更新批次先确认双方成立与对抗，再计算必中：`有效领域 → 纳入目标 → 对象/豁免 → 相持或反领域抑制 → 效果减轻 → 提交`。必中确定作用方式，不统一等同伤害或无视所有防御；离开范围或建立有效保护会改变结果。该顺序只协调本 Mod 的领域，不重排整个 Minecraft 的同 tick 事件。

| 交互                         | 规则                                             |
| ---------------------------- | ------------------------------------------------ |
| 普通接触攻击 → 无下限        | 拦截后没有接触、黑闪或接触捌                     |
| 适用必中 → 无下限            | 进入领域规则，不被普通投射物拦截层阻断           |
| 必中 → 简易领域              | 保护有效时抑制对应必中，剥离与移动条件按技法处理 |
| 手动攻击/地形伤害 → 简易领域 | 保留普通命中与防御规则                           |
| 展延 → 无下限                | 检查接触中和、输出及与术式并用的限制             |
| 无量空处 ↔ 伏魔御厨子        | 相交区必中对抗与外部斩击破壳分别计算             |
| 外壳破损 → 内部人员          | 开放对应破口或崩解路径，保留其他来源的控制       |
| 零咒力对象 → 御厨子          | 分别检查实体、物体与地形规则                     |
| 不死图腾 → 致命领域          | 尊重死亡拦截，后续独立命中仍可致命               |

首版最多支持两个互相影响的领域，成立后边界不整体移动。新请求或范围变更使整个交互组超限时，在扣费前拒绝。先验证有效相持、明显压制、无有效对抗三种场景，再调输出和维持成本；开放结构或咒力总量均不单独决定胜负。

PvP/友伤规则同时覆盖伤害、控制、禁行及强制迁移。无法排除受保护人员时拒绝纳入或展开。御厨子以命中批次处理实体，地形另走预算，客户端补足斩线密度。

### 空间方案

开放领域直接作用原世界。闭合领域先在预制场地验证真实边界与景象，保持画面和碰撞一致。独立内部场地是处理内外尺度差异的候选，采用前必须证明：

- 外壳和内部共享一个领域 ID、计时及来源世界控制器；重叠领域仍处于同一交战关系。
- 外部破壳、内部相持、救援与破口通行能沿映射传递。
- 人员、坐骑、物品和投射物有明确迁移政策；不支持的组合在成立前拒绝。
- 保存来源维度与退出位置；原位置不可用时，在有限范围寻找安全位置，最后回出生点。
- 控制器发起的内部迁移区别于普通跨维度，状态只推进一次；其他传送按逃离规则处理。

空间样片应在领域制作前完成。未通过时只能交付场地演示；任意地形支持仍需独立验收，不靠临时清空、回填生存建筑实现。

### 结束与恢复

成立前检查资源、容量和空间。区块票据有数量与时限，无法维持时崩解并释放票据及来源效果。术者死亡、取消、掉线或普通跨维度按能力规则终止并结算熔断；其他参与者掉线需保存返回记录。

重启不续播领域。使用内部场地时，在迁移前持久记录来源、实体身份和转移阶段；恢复先核对实体是否存在，再执行一次返回。中途退出、重启和强制终止都需故障测试；资源恢复以最后成功写盘状态为界。

恢复负担按在线模拟时间推进，重登和重生不清空。持续领域某批地形工作超时只终止该批未提交破坏，不改变合法实体效果或必中范围。

## 验收场景

以下为完整功能的验收清单，包含尚未实现的能力。已有自动测试的职责见[架构验证](architecture.zh-CN.md#验证)。

| 场景                                      | 通过条件                                       |
| ----------------------------------------- | ---------------------------------------------- |
| 重包、旧会话、取消、重连及资源竞争        | 一次提交；预留释放正确；余额和恢复负担不被重置 |
| 无下限对近战、术式、投射物与环境伤害      | 按来源拦截；未接触不触发黑闪/捌                |
| 飞行、移动目标、墙体、新搭墙与保护障碍    | 扫掠与可见主体一致；茈贯穿，其他术式遵循各自遮挡规则 |
| 捌、防御差异及高阶变体                    | 输出有界，资格和发动条件完整，版本代价不混用   |
| 同批/错批领域、准备中受击、三领域链式相交 | 先建关系再判必中，超容量在扣费前拒绝           |
| 简易领域、展延与手动攻击                  | 保护只作用指定层，互斥能力不并用               |
| 开放领域破壳、外部救援及内部迁移          | 内外规则与通行一致，迁移不重复、不遗留实体     |
| PvP/友伤、零咒力对象、图腾与持续必中      | 目标规则覆盖伤害及控制，死亡处理保持原生语义   |
| 容器、红石、流体、保护回调和队列失效      | 按当前方块提交，无重复掉落或越权破坏           |
| 延迟、抖动、挥空与扫击                    | 一次预备一次消费，迟到请求不追认伤害           |
| 晚加入、过期事件、资源重载和退服          | 快照有效，无重复爆发、旧状态或资源泄漏         |
| 三语、UI 比例、皮肤、装备和最低画质       | 文本可读，必要战斗信息一致，动作不穿帮         |
| 完整角色档、成长档和合作挑战              | 分别验证还原、资源循环与反制空间               |
