# 咒誓：设计与范围

Cursed Oath（咒誓）是以《咒术回战》为题材的 Minecraft Fabric 战斗 Mod。本文包含漫画全篇剧透。试玩方法见 [README](../README.md)，已实现规则见[战斗规格](combat.zh-CN.md)，原作依据见[来源与核验](sources.zh-CN.md)。

## 体验目标

保留 Minecraft 的第一人称、准星、移动、装备、建造和地形互动，让近战、术式组合、黑闪与领域共同构成战斗。优先面向单人与 2—4 人合作 PvE；长期目标是把探索、修炼和祓除接入生存流程。

高阶术师可以压倒普通敌人，致命领域应能迅速终结无防备目标。平衡来自取得条件、出手时机、资源、情报、反制和战后代价；完整五条或宿傩配置不以公平竞技为目标。

无下限与御厨子优先覆盖牵引、排斥、接触防御、远近斩击、持续破坏和领域交互，以此检验战斗、表现与联网。具体适配及证据边界见[来源与核验](sources.zh-CN.md)。

## 当前交付边界

目前是通过管理员命令开放能力的同世界战斗原型。

| 范围       | 已实现                                               | 限制                                             |
| ---------- | ---------------------------------------------------- | ------------------------------------------------ |
| 无下限     | 中性防御、苍、赫、常规茈、无量空处                   | 防御只覆盖指定来源；没有六眼自动筛选或高阶派生   |
| 御厨子     | 解、接触捌与网格、伏魔御厨子                         | 普通活体统一按有咒力处理；没有灶或扩张对象的斩击 |
| 领域空间   | 固定范围、闭合球壳、内部绘景、开放领域               | 留在原世界，不传送、不复制地形；内部没有扩大尺度 |
| 领域交互   | 重叠区域相持、外部破壳、简易领域剥离、展延接触中和   | 所有重叠领域参与；没有精细度比较                 |
| 通用能力   | 近战强化与概率黑闪、自疗、独立熔断负担               | 没有黑闪觉醒、对外治疗或熔断修复                 |
| 操作与表现 | 不暂停的术式轮盘、快捷施放、PAL 动作、三语界面与字幕 | 方块手近似手印；声音复用原版素材                 |

咒力余额、恢复和熔断负担持久化，活动施法与领域不跨重启保存。自疗和术式反转资格独立；目前通过练习命令一并授予。玩家资格与资源保留，领域锚点及飞行实体不存盘；重启不会恢复在途攻击。具体控制、伤害及破坏规则见[战斗规格](combat.zh-CN.md)。

## 设计约束

- **战斗：**用距离、动作和资源制造进攻窗口；防御、攻击和治疗竞争同一咒力。保留原生伤害、装备和死亡流程。
- **输入：**保留原版攻击与物品使用，术式按键可改绑，轮盘不中断世界。黑闪机会由服务端结算，不要求微秒级输入。
- **表现：**角色、建筑和材质保持方块与像素语言；术式用清晰主体表达体积，以运动表达吸引、排斥或贯穿。视觉不能代替实际判定。
- **可读性：**优先保留攻击方向、危险边界、命中和防御失效提示。装饰密度与减闪光设置不改变玩法。

## 后续方向

生存成长采用“学习 → 世界内试炼 → 解锁运用方式”，先试用路线再形成身份；换路线不依赖死亡重抽，随机黑闪次数不作为主线门槛。六眼、身体条件、生得术式、反转术式和结界熟练度分别授权。

后续候选包括零咒力身体、灶、强化咏唱、范围茈、对外治疗及危险的熔断修复。极之番、召唤、灵魂、适应和规则领域随对应路线扩展，不预先建立通用系统。独立领域内部空间、返回记录、精细手指和专用录音尚未实现。

扩展前核实原作前提、对象、豁免与反例，再制定实现和验收范围。多人压力及设备验收方法见[表现制作](presentation.zh-CN.md#验收与性能)。
