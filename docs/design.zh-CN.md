# Cursed Oath：设计总纲

**咒誓**是一款以《咒术回战》为题材的 Minecraft Fabric 战斗 Mod。本文包含漫画全篇剧透，描述完整制作目标；可试玩内容见 [README](../README.md)，实现规则见[战斗规格](combat.zh-CN.md#当前原型)。

## 体验目标

玩家在方块世界中建立自己的术师身份：探索、建造、修炼与祓除构成长期生活，近战、术式组合、黑闪和领域构成战斗。优先支持单人与 2—4 人合作 PvE。

保留原版第一人称、准星、移动、装备和地形互动。高阶术师允许明显压倒普通敌人，成熟致命领域可以迅速终结无防备目标。平衡来自取得条件、出手承诺、资源、情报、反制和战后代价；完整五条或宿傩的展示档不以公平竞技为目标。

原作证据、游戏改编和待核假设分别记录，见[来源与核验](sources.zh-CN.md)。

## 首批体系

无下限与御厨子覆盖接触防御、牵引、排斥、远近斩击、持续破坏和领域对抗，适合共同检验战斗、表现与联网。

| 体系     | 基础能力                   | 高阶目标                             |
| -------- | -------------------------- | ------------------------------------ |
| 无下限   | 中性防御、苍、赫、体术衔接 | 常规茈、无量空处、强化咏唱与空间组合 |
| 御厨子   | 解、接触捌、地面派生       | 伏魔御厨子、灶及扩张对象的斩击       |
| 通用技术 | 咒力操作、黑闪、自疗       | 反领域、熔断处理与路线限定的突破     |

六眼、身体条件、生得术式、反转术式和结界熟练度分别授权。生存玩家逐步取得资格，完整角色展示可以授予成套配置；拥有一种术式不自动继承原作使用者的全部能力。

两套体系稳定后，以极之番「陨」验证另一种大规模攻击。规则领域、召唤继承、灵魂与适应随对应内容扩展；茈、最大输出和特殊斩击保留各自分类。

## 战斗与成长

交锋围绕距离、出手承诺和资源展开：读动作、争位置，以体术或基础术式制造窗口，再决定压制、释放高阶能力或撤退。

- **输入：**保留原版攻击与物品使用；术式选择、释放和咒力操作可改绑。扩展快捷槽或轮盘时保持多人世界连续运行。
- **资源：**咒力储量为主要资源，输出与效率作为能力参数；攻击、防御和治疗竞争同一资源与时机。
- **黑闪：**预备近战提供稳定强化和黑闪机会，服务端确认结果；随机触发次数不作为主线成长门槛。
- **防御：**格挡、咒力防御、无下限、简易领域和展延各有适用层；致命领域保持成立后的威胁。
- **原版互动：**墙体、落差、装备与食物保留价值，伤害和死亡继续经过原生流程。

成长采用“学习 → 世界内试炼 → 解锁运用方式”。玩家先试用路线，再形成主要身份；换路线不依赖死亡重抽，世界敌人也不随玩家整体膨胀。

## 视觉方向

角色、建筑与材质保持 Minecraft 的比例和像素语言；能量可使用连续曲面、丝带与局部扭曲。蓄势、释放、接触和余波各有轮廓：苍向内收，赫向外推，茈强调融合与路径，御厨子通过切线和地形断面表达斩击。

第一人称读得出手势与方向，旁观者读得出身体动作。领域由空间、声音和规则变化形成压迫感。降低震动、闪光和装饰密度后仍需保留危险边界、命中与防御失效提示。制作方法见[表现制作](presentation.zh-CN.md)。

## 交付顺序

当前已具备基础术式与常规茈原型；领域空间样片、多人性能基线和完整美术验收尚未完成。以下按依赖排列，不表示前序阶段已全部通过。

| 阶段           | 内容                                                   | 完成标准                                                   |
| -------------- | ------------------------------------------------------ | ---------------------------------------------------------- |
| 工程与空间样片 | 专服、三语、玩家动作、渲染、分批破坏；闭合领域空间试验 | 建立兼容和性能基线，验证内外映射可行性                     |
| 基础战斗       | 近战、黑闪、自疗与资格；苍/赫/中性防御、解/捌          | 命中、消耗、取消、恢复及延迟行为可重复验证                 |
| 高强度单技     | 常规茈、持续斩击、完整第一/第三人称演出                | 高速碰撞、保护路径及双人大招可读性通过验收                 |
| 领域对战       | 两领域、反领域、熔断和空间集成                         | 相持、破壳、救援、退出恢复一致；空间受限时明确标记场地演示 |
| 两套体系完成   | 灶、后期派生、完整角色展示                             | 对应原著细则与反例测试完成，任意地形领域通过验收           |
| 生存与扩展     | 获取、成长、遭遇、极之番「陨」及其他路线               | 探索与资源循环成立，性能和兼容门槛持续满足                 |

每项能力在制作前补齐所需原著核验。各阶段分别用完整角色展示、可控制条件的规则实验和真实资源挑战，检验还原、正确性与体验。
