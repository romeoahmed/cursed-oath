## 使用标准

原作正文与作者修订优先，公式书结合勘误。官方动画支持已展示行为和演出，授权产品支持对应名称；游戏平衡规则不能推回漫画机制。

“已核实”指直接读到来源内容，“工作规格”指 Mod 设计，“待核”指缺少可定位的原著或译本证据，“待验”指尚需代码或实机验证。网页简介的核验范围仅限简介本身。

## 常规茈的实现依据

R01 记录导演向作者询问茈的形成方式，作者给出碰撞意象，动画采用苍、赫碰撞后融合的演出。当前准备动画据此安排蓝红会合后出现紫色。该依据不包含后期全部变体、精确威力或无条件物质抹除；伤害、路径、破坏和豁免见[游戏规格](combat.zh-CN.md#术式与地形)。

## 黑闪的威力基准

[ABEMA 七海黑闪说明](https://times.abema.tv/articles/-/10157406)记载其威力平均为通常打击的 **2.5 次方**。这是配信平台解说；漫画第 6 卷正文和作者附页仍待直接核页。

当前实现以原生减伤前伤害为游戏单位，最低基数、触发概率和预备窗口均为适配参数，见[近战与黑闪](combat.zh-CN.md#近战与黑闪)。

## 当前实现与还原边界

[动画官方人物页](https://jujutsukaisen.jp/character/category6.php)直接确认无下限呪術名称；[ABEMA 五条能力说明](https://times.abema.tv/articles/-/8638921)补充渐近防御、苍的吸引、赫的排斥与反转前提。后者是配信平台解说，核验范围不等同漫画正文。

| 实现     | 判断与边界                                                                                                                                                                  |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 中性防御 | 目前是指定伤害源拦截与近处投射物偏转；**尚未还原渐近减速**、六眼自动筛选或必中/展延突破。不能称为完整无下限。                                                               |
| 苍 / 赫  | 移动吸引场与飞行后排斥符合基本方向。苍的固定寿命、脉冲与停止方式是简化；赫峰值取苍完整六段的两倍是游戏换算，不证明所有场景实际伤害恒为两倍。                                |
| 常规茈   | 蓝红碰撞后形成紫色与 R01 相符；连续球形贯穿不依赖挖掘进度。有限伤害、保留方块与施法者豁免是游戏规则，不等于无条件抹除。 |
| 解 / 捌  | 远距薄斩与近接自适应伤害具有区分；四格接触是可玩性宽限。当前捌把接触与体积网格合在一次释放，属于改编，尚不能等同原作所有接触/地面派生。护甲、最大生命值只是防御强度的代理。 |
| 反转术式 | 原生自疗原型；暂与赫共用一个修习资格。自疗、对外输出正能量和术式反转的精细资格仍未拆分。                                                                                    |
| 黑闪     | 保留乘方；三秒预备、20% 概率、最低基数和武器兼容均为游戏化规则。目前只绘制绯红丝带，黑色内核与空间扭曲仍未完成；尚无专注、觉醒或术式恢复系统。                              |

## 制作前必须补齐的原著细则

对应能力制作前，记录版本、卷/话、位置、释义、反例及实现影响；证据未补齐时保留工作规格状态。

| 优先级 / 主题          | 必须核实的边界                                         | 影响的规格                             |
| ---------------------- | ------------------------------------------------------ | -------------------------------------- |
| 基础：六眼与无下限     | 操作精度、自动防御、维持与恢复；环境伤害如何处理       | 防御筛选、天赋资格、成本与例外         |
| 基础：黑闪             | 主动控制限制、接触对象、格挡情形及后续收益             | 一次接触机会、概率与觉醒               |
| 基础：恢复与赫         | 正能量生成、自疗、术式反转的资格与并行限制             | 自疗样板、赫的前置及资源竞争           |
| 基础：解与捌           | 领域内外接触条件、对象分类、输出与防御边界             | 远距/接触版本分离，不做无限即死        |
| 领域：交锋             | 目标/接触豁免、内外必中关系、外壳强度、开放范围与束缚  | 两领域相持、外部攻击与人员纳入         |
| 领域：反领域与熔断     | 简易领域剥离、展延并用限制、熔断期间能力、危险修复     | 状态互斥、恢复负担、失去保护时点       |
| 高阶：灶与特殊斩击     | 灶的前置/对象/领域内外差异；对象扩张与束缚前后发动条件 | 独立变体和长期代价，避免混合最有利状态 |
| 高阶：无下限派生       | 输出强化、远距组合、范围茈及自身影响；位移条件         | 特定派生，不做无条件传送或无敌         |
| 扩展：极之番与其他路线 | 陨的运动/波及；召唤、适应、灵魂和规则领域分别核验      | 每条新路线先有反例测试再扩展系统       |
